# 완료 점검 체크리스트

SKILL.md A-6 · B-6에서 읽는다. 항목마다 **✅ · ❌ · 해당 없음**과 근거(파일 · 줄 · 명령 결과)를 대화에 표로 보고하고, 결정 기록 "작성 결과" 절에 한 줄로 요약한다. **❌가 하나라도 있으면 "완료"라고 하지 않는다** — 고친 뒤 그 항목부터 다시 확인한다.

"해당 없음"은 프로필상 그 항목이 없을 때만 쓴다(예: 혼자 개발이면 A12 · A13).

## 모드 A — 새로 작성

| # | 항목 | 확인 방법 |
|---|---|---|
| A1 | 입력 자료(본문 · 그림 · 평가 기준 · 기존 코드)를 모두 읽었다 | 결정 기록 1장의 읽은 자료 목록과 실제 입력 자료 대조 |
| A2 | 기획서가 "이미 했다"고 적은 작업의 원자료를 확인했고, 없으면 그 작업을 한 사람에게 요청을 보냈다(또는 없다는 답을 기록했다) | 결정 기록 1장 · `docs/request/` |
| A3 | 질문 목록의 모든 갈래를 지났다. 건너뛴 갈래는 이유(해당 없음 · 회신 뒤로 미룸)를 적었다 | `references/questions.md` 목차와 결정 기록 대조 |
| A4 | 모든 답이 결정 기록에 날짜 · 결정자와 함께 있다 | 결정 기록 2장 |
| A5 | 점검 스크립트 오류 0, 자체 시험 통과(첫 실행이 0이었다면 일부러 넣은 오류가 잡히는 것도 확인) | `node docs/check-docs.mjs` · `--self-test` 출력 |
| A6 | 결정 기록의 결정이 두 문서에 모두 들어갔다 | 결정 항목마다 두 문서에서 해당 위치를 찾아 대조 |
| A7 | 값은 한 곳에만 있다 — 설정값 반복 후보 경고를 하나씩 판단했다(인용 · 용어 이름 · 그 문서가 원본인 목표만 남김) | 점검 스크립트의 경고 목록 |
| A8 | 모르는 값을 채우지 않았다 — 모든 U에 지금 아는 것 · 누가 정함 · 정해지면 바뀌는 곳이 있다 | 점검 스크립트(빈 칸은 오류) + U 표 훑기 |
| A9 | 출처를 지켰다 — 측정값에 원자료 위치(없으면 "원자료 없음"), 해마다 바뀌는 외부 사실은 1차 출처 · 확인일 또는 U, 계획을 완료로 쓰지 않았다 | 본문의 수치 · 제도 · 외부 사양 훑기 |
| A10 | (기획서가 있으면) "기획서에서 바뀐 점"과 X 표가 있고, 결정 중 기획서와 달라진 것이 모두 실렸다 | PRD 해당 장과 결정 기록 대조 |
| A11 | 문구 규칙의 "쓰지 않는 표현"이 문서에 없다(규칙 표 · 인용 안은 제외) | 쓰지 않는 표현 검색 |
| A12 | (팀이면) 문서 지도 · 알림판 · 수정 기록이 있고, 파트 안내 문서가 가리키는 절 · ID가 실제로 있다 | `docs/README.md` · `node docs/check-docs.mjs --also {파트}/CLAUDE.md …` |
| A13 | (팀이면) 요청 문서에 상태 배너가 있다 | `docs/request/` |
| A14 | "결정에 없던 것"(쓰다가 찾은 빈틈 · 결정에서 따라 나온 요구 · 새 위험)을 따로 보고하고 사용자 확인을 받았다 | 결정 기록 3장 |
| A15 | 남은 일(U · 회신 대기)과 다음 문서 안내를 알렸다 | 보고 · 결정 기록 4장 |
| A16 | 두 문서가 용어집의 용어를 같은 뜻으로 쓴다(같은 대상을 다른 이름으로 부르지 않는다) | 용어집의 용어마다 두 문서에서 검색 |

## 모드 B — 갱신

| # | 항목 | 확인 방법 |
|---|---|---|
| B1 | 바뀐 결정 · 회신 내용을 결정 기록에 적었다 | 결정 기록 |
| B2 | 해당 U의 "정해지면 바뀌는 곳"을 모두 고쳤고, 해소된 U의 "지금 아는 것"을 `**확정 YYYY-MM-DD**: …`로 바꾸고 본문 ⚠ 표기를 지웠다 | U 표 · 해당 U ID 검색 |
| B3 | A5 · A7 · A8 · A9 · A11 · A16을 다시 확인했다 | 위 방법 그대로 |
| B4 | 두 문서의 버전 · 수정 기록 · 결정 이력, (팀이면) 알림판을 고쳤다. 기획서와 달라졌으면 "기획서에서 바뀐 점"에도 | 두 문서 머리 · `docs/README.md` |
| B5 | 처리한 요청 문서의 배너를 ✅로 바꿨다(반영하지 않은 것도 회신에 적었다) | `docs/request/` · `docs/response/` |
| B6 | "결정에 없던 것"과 남은 일을 보고했다 | 보고 |
